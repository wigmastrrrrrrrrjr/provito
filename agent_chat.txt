  Current state (v2.0.3)
  ----------------------
  - Engine: GeckoView 140 (Firefox ESR). Every tab is a private GeckoSession.
  - Internal pages load from resource://android/assets/<file>.html
    (NOT file:///android_asset/ - that is a WebView-only path and 404s here).
  - Custom network error page: assets/error.html.
  - resource:// URLs are masked in the address bar, tab switcher and titles.
  - Releases: one APK per ABI (arm64-v8a, armeabi-v7a) plus SHA256SUMS.
  
  Contract: pages -> native
  -------------------------
  Pages send actions as top-level navigations:
    location.href = 'provito://...'
  Native intercepts the navigation, handles the action and denies the load, so
  the page stays where it is. Do not use iframes or a JS bridge.
  
  Origin-gated actions (sender must be the matching internal page):
    from settings.html:
      provito://set?k=<key>&v=<value>
      provito://act?name=<action>
    from tabs.html:
      provito://tab?op=select&id=<n>
      provito://tab?op=close&id=<n>
      provito://tab?op=new
    from unsafe.html:
      provito://unsafe-continue?u=<encoded url>
    from error.html:
      provito://retry?u=<encoded url>
    from settings/tabs/unsafe/error:
      provito://home
  
  Settings keys (provito://set?k=...&v=...):
    search_engine          brave | duckduckgo | mojeek
    block_ads              0 | 1
    unload_tabs            0 | 1
    auto_ui_resize         0 | 1
    wipe_on_exit           0 | 1
    update_check_enabled   0 | 1
    onion_mode             0 | 1
  
  Settings actions (provito://act?name=...):
    orbot-install, orbot-status, check-updates, unsafe-update, wipe
  
  Page data injected via URL fragment
  -----------------------------------
  settings.html#v=<ver>&search=<engine>&block=<0|1>&wipe=<0|1>&unload=<0|1>
                &resize=<0|1>&onion=<0|1>&updchk=<0|1>&blocked=<n>&orbot=<0|1>
  tabs.html#data=<url-encoded JSON array of {id,title,url,unloaded,current}>
  unsafe.html#level=<malware|phishing>&u=<encoded url>
  error.html#u=<encoded url>&t=<reason>&h=<hint>&c=<error code>
  
  Parsing notes:
    - Values are percent-encoded. URLSearchParams(location.hash.slice(1)) works.
    - tabs.html JSON is URL-encoded; decode it before JSON.parse. Spaces may
      arrive as "+" (URLEncoder); replace "+" with "%20" before decoding.
    - Keep every page self-contained: inline CSS/JS, no external files.
